# UNO em C 🎴

Este é um projeto do jogo **UNO**, desenvolvido em linguagem C como trabalho final de uma disciplina da faculdade. O jogo é executado no terminal e segue as regras clássicas do UNO, com suporte para múltiplos jogadores.

## 🧩 Funcionalidades

- Jogo completo no terminal
- Cartas com cores e números
- Cartas especiais: +2, +4, inverter, pular, coringa
- Validação de jogadas
- Troca de turno automática

Este projeto foi desenvolvido como avaliação final da disciplina de Linguagem de Programaçaõ 1, no curso de Sistemas de Informação na UNEB.
